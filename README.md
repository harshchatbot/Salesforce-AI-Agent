# HealthAssist — Salesforce Agentforce Healthcare AI Agent

A hands-on Salesforce Agentforce project for learning how to design,
build, secure, integrate, test, and deploy an enterprise AI agent.

> 🚧 This project is currently being built and documented.

## What We're Building

HealthAssist is a healthcare-focused AI agent built using Salesforce
Agentforce.

The project will explore:

- Agentforce fundamentals
- Agent reasoning and actions
- Salesforce data grounding
- Flow and Apex actions
- External REST API integration
- NPI Registry provider lookup
- AI security and governance
- Guardrails and human escalation
- Agent testing
- Source control and deployment

## Documentation

Learning notes and implementation decisions are available in the
[`docs`](./docs/) directory.

## Disclaimer

This project is for educational and demonstration purposes.

All healthcare/patient data used in this repository is synthetic.
No real patient information or protected health information (PHI)
should be stored in this repository.
